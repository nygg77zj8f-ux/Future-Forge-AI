# Future Forge AI

## About

Future Forge AI is a Python project that I developed to improve my programming skills and practice using functions in Python.
This project evaluates a student's portfolio based on GPA, English level, GitHub projects, and certificates. 
It then calculates a portfolio score and provides personalized suggestions for improvement.


## Features

- User information input
- GPA evaluation
- English level evaluation
- GitHub project evaluation
- Certificate evaluation
- Portfolio score calculation
- Personalized improvement suggestions


##Technologies Used

- Python
- Google Colab
- Functions
- Conditional Statements (if / elif / else)
- User Input
- Return Statements
- GitHub
